N3 터치 단어장
==============

동작:
- 화면에 가타카나 읽기 → 한자/표기 → 한국어 뜻 순서로 표시
- 화면 아무 곳이나 터치하면 다음 단어
- 마지막 단어 다음에는 첫 단어로 돌아감
- 앱을 껐다 켜도 마지막 위치를 기억

현재 포함 단어: 200개
이 단어 목록은 링크된 영상에서 복사한 것이 아니라 별도로 구성한 학습용 스타터 목록입니다.
JLPT는 현재 공식 어휘/한자/문법 목록을 공개하지 않으므로 '공식 N3 단어 목록'은 아닙니다.

Android Studio 사용:
1. 이 폴더를 Android Studio에서 Open
2. Gradle Sync
3. 휴대폰 또는 에뮬레이터에서 Run

단어 수정:
app/src/main/assets/words.csv
형식: reading,word,meaning
